# Thirty Days Dark

A practical field manual for the first 30 days after the grid and internet go down, written to help you thrive rather than just survive. It covers running a household, lifting a village, keeping morale up, and improvising clever fixes.

The book is written as Markdown chapters and printed to an A5 PDF. It is designed to sit on a shelf and work with no power and no net.

## Safety
This book covers first aid and home care only. It is not medical advice. Every safety-critical number in it cites WHO, CDC, the Red Cross or an equivalent source.
